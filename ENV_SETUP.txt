CUTPILOT AI v0.2 — ENVIRONMENT SETUP

Required for AI planning + narration:
  OPENAI_API_KEY=your_key_here

Recommended defaults:
  OPENAI_EDITOR_MODEL=gpt-5.6-luna
  OPENAI_TRANSCRIBE_MODEL=whisper-1
  OPENAI_TTS_MODEL=gpt-4o-mini-tts
  TRANSCRIBE_PROVIDER=openai
  SCENE_THRESHOLD=27
  MAX_UPLOAD_MB=1500
  DATA_DIR=/app/data

For local Whisper instead of API transcription:
  pip install -r requirements-local.txt
  TRANSCRIBE_PROVIDER=local
  WHISPER_MODEL=small
  WHISPER_DEVICE=cpu
  WHISPER_COMPUTE=int8
